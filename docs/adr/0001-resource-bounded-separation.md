# ADR 0001: Define power as resource-bounded separation

- Status: accepted
- Date: 2026-08-29

## Context

“More powerful than Transformers” is ambiguous because sufficiently general
neural computational models may be universal under idealized assumptions.

## Decision

Claims target strict capability advantages under named resource bounds. Claims
must distinguish computability, complexity, learnability, generality, autonomy,
efficiency, and physical realizability.

## Evidence and falsifier

This framing produces measurable comparisons and admits formal separations. It
should be replaced if a genuine computability-theoretic separation is proved or
if no scientifically meaningful bounded comparison can be specified.

## Cost and complexity delta

Adds one mission invariant and seven controlled dimensions; no runtime dependency.

## Consequences and reversibility

Global superiority claims are rejected. The decision is isolated in MissionSpec
and can be superseded by a later ADR with stronger evidence.
