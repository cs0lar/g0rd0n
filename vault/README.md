# g0rd0n Research Vault

This directory is the human-facing projection and authoring surface for
structured research state. It is not the machine source of truth.

Generated notes contain an ownership warning and a `Human notes` region. Edit
only between the `g0rd0n:manual:start` and `g0rd0n:manual:end` markers.
Regeneration replaces every other section. Manual edits become reviewable
`HumanEdit` proposals; they are never silently imported into the ledger or
knowledge store.

The projector creates the roadmap folders as they become necessary. Raw evidence
is copied to `99-generated/artifacts/` under its SHA-256 digest and linked from
the objects that reference it.
